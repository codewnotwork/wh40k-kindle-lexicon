# Changelog

## v1.6
- Credits page and file metadata now carry the CC BY-SA 3.0 licence notice and the "unofficial, not affiliated with Games Workshop" statement.
- Dictionary renamed to "Warhammer 40k Lexicon (unofficial)".

## v1.5
- Articles that share a headword (such as a character and a novel) are merged into one entry with numbered meanings. Before this, the Kindle showed only one of them.
- Finds the custom entries file even when a browser saved it as `wh40k_custom_entries (1).txt`, and warns loudly if it's missing.
- Adds curly-apostrophe possessives (Calgar’s).

## v1.4
- Custom entries file, merged in at build time. Starts with about 165 Fenrisian terms.

## v1.3
- Distinctive parts of names (Calgar, Eisenhorn) find their full article.

## v1.2
- Finds kindlegen automatically in more places; `--kindlegen` option.

## v1.1
- Fixed the wiki redirect listing.

## v1.0
- First version: wiki download, summaries, plurals, Kindle dictionary build.
